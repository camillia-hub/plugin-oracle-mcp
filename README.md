# Oracle MCP

Queries an Oracle database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/oracle-mcp

Installs from the Camillia hub as `oracle-mcp-a902b5`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
